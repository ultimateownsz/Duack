# Duack.Sample.Crossfade

Minimal crossfade showcase using the KNI (web) adapter. Keys:

- `1` / `2` / `3` — play Track A / B / C (triggers a crossfade from the current track)
- `Space` — play the next track
- `C` — toggle crossfade on/off (green = equal-power ramp, red = instant hard cut)

A bottom-right button is also clickable to toggle crossfade. The legend overlay (bottom-left) explains the controls.
